GradLink · visual direction

Ten original UI concepts

Every pixel below is drawn from scratch — no templates, no screenshots, no borrowed layouts. What differs is not the colour, it is the structure: each concept organises the same content a different way, because that is what actually makes a product feel like itself. All ten are buildable in Compose with the libraries already in the app.

Pick a number. I build that one into the theme and the home screen — not the other nine.
