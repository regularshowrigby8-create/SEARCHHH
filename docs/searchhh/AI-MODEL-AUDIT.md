# Searchhh — free API model audit

**Checked: 29 September 2026.** This is a documentation/public-discovery audit, not an inference certification.

## Bottom line

**Do not import the supplied list as “100 permanently free working API models.”** It mixes valid free tiers, retired routes, recurring credits, evaluation trials, paid APIs, specialist modalities and unofficial consumer endpoints. Free plans remain allowed in Searchhh; open weights alone do not supply a free hosted API.

The numbered dispositions below cover **all 100 supplied entry numbers**, grouped by provider. Model-level checks are identified explicitly; provider-level rejection does not pretend every model ID/context limit was independently tested. Unresolved entries remain unresolved, not silently approved.

Added **22 documented candidate routes/replacements**, with per-entry qualifications below. These are **not 22 newly working integrations**, and multiple routes can serve the same underlying model. No additions were enabled in the APK.

**No provider here is certified “forever,” unlimited, globally available, or permanently key-valid.** Keys can expire/revoke, catalogs change, and quotas are often account/project-wide. No user keys or private data were used.

### Corrections that matter to implementation

- **Google:** confirmed hosted Gemma IDs are `gemma-4-31b-it` and `gemma-4-26b-a4b-it`. Google says rate limits are per project, not per key, and current values are in AI Studio. Free-tier product-improvement/data-use terms require consent. Do not send profile/email/secrets by default.
- **Groq:** the old Llama/Gemma/Mixtral/DeepSeek roster is not the current public free roster. Different tiers can have different retirement dates. No model is approved merely because its weights are open.
- **Cloudflare:** use a scoped token **and account ID**. The source catalog includes non-text models. A price-table entry or browser playground is not, by itself, proof the model is available on Workers Free.
- **Mistral:** #57 and #59 duplicate the 3B ID while #57 labels it 8B. The documented 8B version `ministral-8b-2512` is a correction, not an extra model to inflate the count. Monthly credits are now confirmed from current primary docs; old Experiment-plan figures should not override them.
- **Cohere:** current Command A/A+ models are real. Their existence does not remove trial/production restrictions. Do not equate 1,000 evaluation calls with unrestricted production use.
- **BigModel vs Z.AI:** `open.bigmodel.cn` and `api.z.ai` have different credentials and catalogs. China’s GLM-4.5 retirement/redirect cannot be applied automatically to international Z.AI.
- **Aion:** Free rate-limit tier plus nonzero token prices is ambiguous. No zero-cost entitlement has been established, so do not activate it as guaranteed free.

## Evidence boundaries

- **Verified from primary docs:** the quoted provider pricing/plan/deprecation statements, the linked model listings, and the public OpenRouter metadata observations.
- **Not verified:** successful signup from every country, no-card onboarding for every provider, ownership/validity of a user key, account entitlements, all original context/output-size claims, model accuracy, inference latency, or successful inference.
- **Not exhaustively checked:** every original NVIDIA/Novita/HF model ID; every Cloudflare model’s Free/Paid gate; all Mistral aliases; current SiliconFlow regional availability. Their table dispositions must not be read as a completed live-model test.
- **Specialists:** image generation, speech and embeddings can be useful later, but are excluded from the evidence-review model count. No on-device/self-hosted inference is substituted for external APIs.
- **Continuous discovery:** only documented catalog refresh belongs in the initial implementation. It must not silently authorize new providers, share more personal data, register accounts or create keys.
